Проект по технологиям программирования. Сайт с трекером привычек в виде небольшого сада с растениями, которые растут по мере того, как часто вы выполняете конкретную привычку. В проекте присутствуют достижения, украшения для сада, множество вариантов растений. Растения могут как расти, так и увядать. Присутствуют уровни, стрик за выполнение привычек.

Распределение обязанностей: Кузнецов Егор - тимлид/разработчик, Крашенинников Андрей - тестировщик, Рябов Андрей - разработчик, Белоусова Анастасия - дизайнер, Ошарина Ева - дизайнер.
